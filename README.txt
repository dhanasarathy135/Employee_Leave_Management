EMPLOYEE LEAVE MANAGEMENT SYSTEM
=================================
Technology: HTML, CSS, PHP, MySQL, XAMPP

1. Extract to:
C:\xampp1\htdocs\EmployeeLeaveManagementSystem
(or your Apache htdocs folder)

2. Start Apache and MySQL in XAMPP.

3. Open:
http://localhost/phpmyadmin/

4. Import database.sql.

5. Run:
http://localhost/EmployeeLeaveManagementSystem/

ADMIN:
http://localhost/EmployeeLeaveManagementSystem/admin/
Username: admin
Password: admin123

USER FLOW:
Register -> Login -> Dashboard -> Apply Leave -> My Leaves

ADMIN FLOW:
Admin Login -> View Applications -> Approve/Reject/Cancel -> Save

DATABASE:
employee_leave
Tables: employees, leave_applications
